# EnumURL Support

EnumURL is a deliberate web browser for iOS: it only opens the pages you've explicitly added — nothing else. Each page ("pagelet") keeps its state while you switch between them or background the app, so no reloads, lost scroll positions, or re-typed forms.

## Get the App

- **TestFlight beta:** [testflight.apple.com/join/DE6FKwan](https://testflight.apple.com/join/DE6FKwan)
- **App Store:** coming soon

## Privacy Policy

EnumURL does not collect any data. Note that EnumURL does not currently support ad blockers, content blockers, or browser extensions, and makes no guarantees about the privacy of the sites you visit or the activity/actions you perform while using it. See the full [Privacy Policy](PrivacyPolicy.md).

## Support

For help, bug reports, or feature requests, please [open an issue](../../issues).

When reporting a bug, it helps to include:

- The app version you're running
- Your iOS version and device model
- What you did, what you expected, and what happened instead
